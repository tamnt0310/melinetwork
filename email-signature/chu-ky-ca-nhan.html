Cách cài đặt

Gmail (trên trình duyệt)

  1. Bấm Sao chép chữ ký ở trên
  2. Gmail → biểu tượng bánh răng → Xem tất cả chế độ cài đặt
  3. Kéo xuống mục Chữ ký → Tạo mới → đặt tên
  4. Dán vào ô soạn thảo bằng Cmd/Ctrl + V
  5. Ở Chữ ký mặc định, chọn chữ ký vừa tạo cho cả thư mới và thư trả lời
  6. Kéo xuống cuối trang, bấm Lưu thay đổi

Outlook (Windows / Mac)

  1. Bấm Sao chép chữ ký ở trên
  2. File → Options → Mail → Signatures (trên Mac: Settings → Signatures)
  3. Bấm New, đặt tên, rồi dán vào khung soạn thảo
  4. Chọn chữ ký này cho New messages và Replies/forwards
  5. Bấm OK

Apple Mail

  1. Bấm Sao chép chữ ký ở trên
  2. Mail → Settings → Signatures, chọn hộp thư bên trái, bấm +
  3. Bỏ tick ô “Always match my default message font” — không bỏ thì Apple Mail xoá sạch định dạng
  4. Dán vào khung bên phải
